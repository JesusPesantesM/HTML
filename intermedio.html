TEMA 01

1. Formularios HTML

Los formularios permiten recopilar datos del usuario. Relaciona cada etiqueta de texto con su campo y elige el tipo de entrada apropiado.

<form action="/enviar" method="post">
  <label for="nombre">Nombre</label>
  <input id="nombre" name="nombre" required>
  <button type="submit">Enviar</button>
</form>
  • type="email" ayuda a validar el formato de correo.
  • required indica un campo obligatorio.
  • Una aplicación o servidor debe procesar los datos enviados.
TEMA 02

2. Tablas en HTML

Las tablas sirven para datos tabulares, no para diseñar el esquema general de una página.

<table>
  <tr><th>Nombre</th><th>Edad</th></tr>
  <tr><td>Ana</td><td>18</td></tr>
</table>
  • <tr> crea una fila.
  • <th> representa una celda de encabezado.
  • <td> representa una celda de datos.
TEMA 03

3. Imágenes y multimedia

Utiliza medios para complementar la información, pero procura que la página siga siendo accesible y rápida.

<img src="paisaje.jpg" alt="Montañas al amanecer">

<video controls>
  <source src="video.mp4" type="video/mp4">
  Tu navegador no admite este video.
</video>
  • Incluye un atributo alt útil en las imágenes informativas.
  • Los controles permiten reproducir y pausar multimedia.
TEMA 04

4. Enlaces y navegación

Los enlaces conectan secciones y páginas. Usa textos descriptivos para que las personas sepan adónde van.

<a href="contacto.html">Contáctanos</a>
<a href="#servicios">Ver servicios</a>

Un enlace con un identificador, como #servicios , permite saltar a una sección del mismo documento.

TEMA 05

5. CSS inicial

CSS mejora la presentación sin mezclar todo el estilo con el contenido. Puede escribirse en una hoja externa.

.tarjeta {
  background: #eef6ff;
  padding: 1rem;
  border-radius: 12px;
}
h1 { color: #126bce; }

Se recomienda guardar los estilos en un archivo como styles.css y enlazarlo desde el documento HTML.

TEMA 06

6. Diseño adaptable

Una web debe funcionar en pantallas pequeñas y grandes. Utiliza unidades flexibles y revisa el resultado en distintos tamaños.

<meta name="viewport"
 content="width=device-width, initial-scale=1.0">

Las reglas CSS como Flexbox, Grid y las media queries ayudan a adaptar el diseño a diferentes dispositivos.

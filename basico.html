LECCIÓN 1

1. ¿Qué es HTML?

HTML significa HyperText Markup Language , o lenguaje de marcado de hipertexto. Es el lenguaje estándar utilizado para definir la estructura y el significado del contenido que aparece en las páginas web.

Con HTML puedes marcar un texto como título, organizar información en párrafos y listas, insertar imágenes, crear enlaces y preparar formularios. HTML no es, por sí solo, un lenguaje de programación: describe y estructura contenido.

HTML, CSS y JavaScript

  • HTML: estructura y contenido.
  • CSS: colores, tipografía y distribución visual.
  • JavaScript: acciones y comportamientos interactivos.
HTML = estructura
CSS = presentación
JavaScript = interacción
LECCIÓN 2

2. Etiquetas, elementos y atributos

Las etiquetas suelen escribirse entre los signos < y > . Un elemento común tiene una etiqueta de apertura, contenido y una etiqueta de cierre.

<p class="introduccion">Estoy aprendiendo HTML.</p>
  • Etiqueta: <p> marca el comienzo de un párrafo.
  • Atributo: class="introduccion" proporciona información adicional al elemento.
  • Contenido: el texto que se muestra en el párrafo.

No todas las etiquetas llevan cierre tradicional. Por ejemplo, <img> inserta una imagen y utiliza atributos para indicar su archivo y una descripción alternativa.

LECCIÓN 3

3. Estructura de un documento

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola, mundo</h1>
    <p>Mi primer sitio web.</p>
  </body>
</html>
  • <!DOCTYPE html> identifica un documento HTML moderno.
  • <html lang="es"> envuelve el documento e indica el idioma principal.
  • <head> contiene metadatos y el título de la pestaña.
  • <body> contiene el contenido visible.
  • <meta charset="UTF-8"> ayuda a mostrar correctamente caracteres y tildes.
LECCIÓN 4

4. Etiquetas básicas

Etiqueta Función Ejemplo de uso
<h1> a <h6> Encabezados por nivel Título y subtítulos
<p> Crear un párrafo Una explicación
<a> Crear un enlace Ir a otra página
<img> Insertar una imagen Ilustrar el contenido
<ul> y <li> Crear listas Enumerar ideas
<strong> Marcar importancia Resaltar un concepto

Escribe el código en un editor de texto y guarda el archivo con la extensión .html , por ejemplo, index.html . Después puedes abrirlo con tu navegador.

¿Qué es, cómo es y cómo funciona?

Comprende las ideas fundamentales antes de empezar a escribir código.

✦

¿Qué es?

HTML significa HyperText Markup Language. Es un lenguaje de marcado que define la estructura y el significado del contenido de una página web.

▤

¿Cómo es?

Se organiza mediante etiquetas y elementos. Las etiquetas permiten identificar títulos, párrafos, imágenes, enlaces, listas, formularios y otras partes.

⌘

¿Cómo funciona?

El navegador interpreta el documento HTML y presenta su contenido. CSS se encarga principalmente del diseño y JavaScript añade interactividad.

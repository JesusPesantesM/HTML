Temas principales

Aplica estas ideas en proyectos reales y recuerda probar la experiencia desde la perspectiva de distintos usuarios.

TEMA 01

1. HTML semántico

La semántica expresa la función del contenido. Facilita la comprensión del código y ayuda a tecnologías de asistencia.

<header>...</header>
<nav aria-label="Principal">...</nav>
<main>
  <article>
    <h1>Título del artículo</h1>
  </article>
</main>
<footer>...</footer>
  • <main> contiene el contenido principal.
  • <article> identifica una composición independiente.
  • <nav> agrupa enlaces de navegación.
TEMA 02

2. Accesibilidad web

Diseña contenido que pueda ser entendido y utilizado por más personas, incluyendo quienes navegan con teclado o lectores de pantalla.

<label for="email">Correo electrónico</label>
<input id="email" type="email" required>

<img src="grafico.png"
  alt="Ventas por trimestre">
  • Asocia etiquetas con sus campos.
  • Usa textos alternativos adecuados.
  • Mantén un orden lógico de encabezados y foco.
TEMA 03

3. Formularios avanzados

Los tipos de entrada y atributos adecuados pueden mejorar la calidad de los datos y la experiencia del usuario.

<form>
  <label for="edad">Edad</label>
  <input id="edad" type="number"
    min="1" max="120" required>
  <button type="submit">Enviar</button>
</form>

La validación HTML ayuda al usuario, pero los datos también deben validarse en el servidor cuando se procesan.

TEMA 04

4. Multimedia y SVG

Integra medios y gráficos escalables cuidando controles, alternativas y compatibilidad.

<video controls preload="metadata">
  <source src="demo.mp4" type="video/mp4">
  Tu navegador no admite video.
</video>

<svg viewBox="0 0 100 100" role="img"
  aria-label="Círculo ilustrativo">...</svg>

Proporciona subtítulos cuando corresponda y evita que el contenido dependa exclusivamente del sonido o del color.

TEMA 05

5. Metadatos y rendimiento

Los metadatos describen el documento y las buenas prácticas de carga pueden mejorar la experiencia.

<meta name="description"
  content="Guía práctica de HTML">
<meta name="viewport"
  content="width=device-width, initial-scale=1">
<img src="foto.webp" alt="Paisaje"
  loading="lazy">

Usa títulos descriptivos, imágenes optimizadas y carga diferida para imágenes que aparecen fuera de la vista inicial.

TEMA 06

6. APIs del navegador

El navegador expone APIs para ciertas capacidades. Revisa siempre los permisos, la privacidad y los requisitos de seguridad.

<button id="ubicacion">Solicitar ubicación</button>
<script>
document.querySelector('#ubicacion')
.addEventListener('click', () => {
if (navigator.geolocation) {
navigator.geolocation.getCurrentPosition(() => {});
}
});
</script>

La ubicación requiere permiso del usuario y suele necesitar un contexto seguro. Solicita solo los datos necesarios.
